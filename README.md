# LESTER — The Litecoin Mascot

Single-page website for the LESTER token on Base (paired with cbLTC on Uniswap v2, launched on Notus Pad).

- `index.html` — the whole site, no build step. Open it or host it anywhere (GitHub Pages works).
- Market data comes from the DexScreener API; burns, supply, burn pot and per-wallet cashback are read live from the Notus launchpad contract on Base through a public RPC. A static snapshot is embedded as fallback.
